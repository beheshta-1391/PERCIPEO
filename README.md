# 🍲 RECIPEO – Discover the Taste of Delicious Food

## 📌 About the Project
RECIPEO is a food and recipe website designed for people who love cooking and discovering delicious meals. It provides an attractive and user-friendly platform where visitors can explore different recipes, find their favorite foods, and read food-related articles.

## ✨ Features
- Beautiful and responsive design
- Explore different food recipes
- Search recipes by name
- Filter recipes by category
- Add and remove favorite recipes
- Dark and light mode
- Mobile-friendly navigation
- Food blog section

## 🧭 Website Sections
1. **Home** – Introduction to the website.
2. **Recipes** – Explore different recipes and meals.
3. **Best** – Discover selected and popular recipes.
4. **Favorite** – Save and view favorite recipes.
5. **Blog** – Read interesting food-related articles.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Font Awesome
- Local Storage

## 🚀 How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enjoy exploring RECIPEO!
